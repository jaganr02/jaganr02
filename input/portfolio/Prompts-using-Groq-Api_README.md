# Prompt Engineering using Groq API

## Objective

Learn the difference between Zero-shot, One-shot, Few-shot, and Multi-shot prompting using the Groq API.

## Tech Stack

- Python
- Groq API
- python-dotenv
- VS Code

## Project Structure

```
app.py
prompts.py
.env
requirements.txt
README.md
```

## Concepts Covered

- Zero-shot Prompting
- One-shot Prompting
- Few-shot Prompting
- Multi-shot Prompting

## Run

```bash
pip install -r requirements.txt
python app.py
```

## Output

The application compares the responses produced by different prompting techniques using the same question.
