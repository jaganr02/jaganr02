# LLM Gemini API

A simple AI chatbot built using Google's Gemini API and Python.

## Features

- Chat with Gemini AI
- Python + VS Code
- Uses Environment Variables (.env)
- Beginner Friendly

## Tech Stack

- Python
- Google GenAI SDK
- python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run:

```bash
python app.py
```
